# La police : Inter

Toute la marque est composée dans **Inter**, et dans rien d'autre. Les titres
se distinguent par la graisse et l'interlettrage, jamais par une seconde
police.

## Ce qu'il y a ici

Quatre fichiers OpenType, les quatre seules graisses que la marque emploie :

| Fichier | Graisse | Emploi |
|---|---|---|
| `Inter-Regular.otf` | 400 | texte courant, légendes, étiquettes |
| `Inter-Medium.otf` | 500 | liens, appuis, libellés de bouton |
| `Inter-SemiBold.otf` | 600 | tous les titres |
| `Inter-Bold.otf` | 700 | le mot-symbole du logo, et rien d'autre |

Version 4.000. C'est la version avec laquelle le logo de ce dossier a été
vectorisé.

## L'installer

- **Windows** — sélectionner les quatre fichiers, clic droit, « Installer ».
- **macOS** — double-clic sur chaque fichier, puis « Installer la police ».
- **Web** — `https://fonts.google.com/specimen/Inter`, ou la version officielle
  sur `https://rsms.me/inter/`.

## Si Inter n'est pas disponible

Dans un courriel, un document partagé ou un gabarit en ligne qui ne permet pas
d'installer de police, utiliser dans cet ordre :

```
Inter, system-ui, -apple-system, "Segoe UI", Roboto, sans-serif
```

Ne pas remplacer par Arial, Helvetica ou Calibri dans un document imprimé qui
porte le logo : l'écart se voit, le mot-symbole du logo étant lui-même en
Inter.
